# Phishing-Email Risk Analyser
Overview:

This project is a Python-based tool designed to analyse the contents of an email and assess the likelihood that it is a phishing attempt.

The program processes an email through multiple rule-based checks, assigns a risk score based on detection indicators and classifies the emails as Low, Medium or High risk. It also provides practical guidance on how to handle suspicious emails.

The goal of this project is not to detect phishing emails perfectly, but to demonstrate foundational cybersecurity thinking, threat awareness and basic programming logic.
